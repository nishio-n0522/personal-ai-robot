# personal-ai-robot

可愛い動物風の外見と日本語の声で日常を支援する、自作卓上パーソナルAIロボットの開発プロジェクトです。高さ25〜30cm、全体予算約20万円を目指し、所有するPi 4・サーバーPC等を活用します。

現在実装しているのは、目の表現を検討する**ブラウザCanvasのPoC**です。466×466円形表示面を想定し、オリジナルの目と6種類のキャラクターを比較できます。会話、カメラ、実ディスプレイ、モーター、実機統合は未実装・未検証です。UI中の「まなざし工房」は試作時の仮表示名で、製品名として合意されたものではありません。

## 起動

Node.js 18以上。アプリと単体テストに追加パッケージは不要です。

```sh
cd personal-ai-robot
npm start
```

http://127.0.0.1:4173 を開きます。サーバーはローカル接続のみを受け付けます。終了は実行ターミナルでCtrl+Cです。Windowsでは `start-preview.cmd` からバックグラウンド起動とブラウザ表示も可能です。PC再起動後は再度実行してください。

カメラ・マイク権限、外部API、外部画像・フォントは使用しません。

## 操作

- まるいロボット、ペンギン、ウサギ、犬、猫、パンダ。全体・顔アップ・片目詳細で比較。
- 通常・興味・眠い、自動視線、手動視線、瞳孔、まぶた、色、瞬き、一時停止。
- 開口部はたれ目・内傾8度・まっすぐ。従来の描画方式も比較できます。
- 虹彩サイズは70〜115%。初期85%。瞳孔・反射も同率で縮小し、100%復元ボタンを備えます。
- 寄せ具合は0〜100px。初期10。正面では値どおり鼻側へ移動し、端の視線では最大24px弱まります。まぶたの外はクリップされます。
- ハイライトは丸1点、大小2点、窓反射、星、ハート、きらめき、弧、なし。**ハイライトの大きさ**を50〜160%、明るさを0〜100%で調整し、標準サイズ100%へ戻せます。変更するのは反射のみで、目の設定や虹彩サイズは保持します。
- OSの動き軽減設定が有効なら停止状態で開始します。「再開」で動かせます。

## 構成

- `src/model.js`: DOM非依存の時間ベース状態更新とまぶた・視線の幾何。
- `src/renderer.js`: Canvas描画、陰影、ハイライト。
- `src/app.js`: 操作UIと左右の同期。
- `docs/`: ロボット全体の計画と、目PoCの設計・検証記録。
- `tests/`: Node標準テストランナーによる単体テスト。

## 検証

```sh
npm test
```

Windows Chromeでハイライト8種×3色×中央・四隅の120状態、瞬き24組、サイズの最小・最大、設定保持を確認しています。単体テストは15件です。ブラウザ表示のfpsは実機性能を保証しません。

任意のブラウザ検証にはPlaywright Coreとインストール済みChromeが必要です。テストコードはPlaywright Coreのモジュールパスを引数で受け取ります。

```sh
npm install --no-save --package-lock=false playwright-core
node scripts/highlights-check.mjs ./node_modules/playwright-core/index.mjs
node scripts/robot-check.mjs ./node_modules/playwright-core/index.mjs
node scripts/convergence100-check.mjs ./node_modules/playwright-core/index.mjs
```

生成結果はローカルの `evidence/` へ保存され、Git管理対象外です。参考画像、ローカルログ、私的な開発記録も含めません。
