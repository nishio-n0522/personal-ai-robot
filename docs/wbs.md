# 開発WBS

更新: 2026-10-13。`大項目.中項目.小項目` の3階層で管理する。表の各行が作業の最小単位。人数/作業時間が未定のため納期は置かず、[ゲート](roadmap.md)と依存関係で進める。

状態欄は **仕様合意 / 実装 / 調達・組立 / 検証** の順。`案`は未合意、`方向合意`は目的のみ合意、`済`はその欄だけ完了、`未`は未着手、`不要`は物理調達対象外、`所有未点検`は保有情報のみ。計画書に記載しただけで仕様合意済みとはしない。実機行はすべて検証未。T番号は [検証計画](verification.md) の方法・受入条件・証拠欄を参照する。新しい合格閾値はまず測定して合意する。
