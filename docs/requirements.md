# 要件

- 可愛い動物風の卓上パーソナルAIロボット。高さ25〜30cm、予算目安20万円まで。
- 将来的に日本語の会話、人物位置の追跡、首・腕の反応を検討。個人識別や足・移動は当面不要。
- 検討環境はRaspberry Pi 4、Intel第11世代PC、型番未確定M5Stack、3Dプリンター。
- 調達候補は秋月電子、Switch Science、Amazon.co.jp。部品購入は別工程。

## この試作

466×466円形AMOLEDを想定したオリジナルCanvasの両目描画。虹彩、瞳孔、反射、曲線のまぶた、視線移動、瞬き、瞳孔変化を実装する。通常・興味・眠いと手動調整を備え、描画と時間ベースロジックを分離する。

6キャラクター、白・青緑・琥珀・任意色、たれ目・内傾・まっすぐ、虹彩倍率、寄せ具合、ハイライトを比較できる。ハイライト切替・サイズ調整で他の設定をリセットしない。

## 未確定

最終外装、首の軸数、腕・指の可動、モーター、重量、安全角度、音声エンジン、部品の現行価格・在庫。人間の首と同じ範囲をそのまま駆動条件にせず、機構と安全限界を優先する。
