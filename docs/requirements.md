# ロボット全体の要件

更新: 2026-10-13。これは personal-ai-robot 全体の要件であり、目の試作だけを製品とする計画ではない。

## 確定している方向・制約

| ID | 要件・制約 |
| --- | --- |
| R01 | 日常支援を行う自作パーソナルAIロボット。可愛い動物風の外見、可愛い日本語の声で会話する。動物種・声・人格は未決定。 |
| R02 | 卓上ぬいぐるみ程度、高さ25〜30cmを目安とする。実部品と機構を測る前に外装寸法を固定しない。 |
| R03 | 目が人物位置を追跡する。個人識別は不要。首が自然に動き、腕・手で反応する。人間程度の首可動域は長期目標で、安全な初期駆動範囲ではない。 |
| R04 | 足・移動は当面不要。首3軸、腕上下、指可動、各モーターは案であり未採用。 |
| R05 | 全体予算は約200,000円まで。既存機材を活用し、新規支出と運用費を分ける。運用費を上限に含める期間は未決定。 |
| R06 | 所有: Raspberry Pi 4、Intel第11世代サーバーPC、型番不明M5Stack、3Dプリンター。容量・OS・電源・機能・稼働状態は要実測。 |
| R07 | 調達先は秋月電子、Switch Science、Amazon.co.jpのみ。商品ページがあっても出品者・版・数量・送料を購入直前に確認する。 |
| R08 | 現在はローカルブラウザ試作。カメラ・マイク許可、外部サービスは不要。購入・実機書込み・公開デプロイは今回の作業範囲外。 |
| R09 | 独立したプロジェクトとして管理し、無関係なプロジェクトや設定を変更しない。未確認の他端末ファイルを移行済みと扱わない。 |
| R10 | 既存の目ライブラリや他製品の画像をコピーせず、独自の柔らかい奥行きのある表情を作る。 |

## MVP案（今後の合意対象）

最小の日常使用版は、固定卓上・電源アダプター給電、1人との短い日本語会話、人物方向への目と制限付き首追従、腕の少数リアクション、頭・背中の押圧反応を対象とする。会話は挨拶・雑談・時刻・利用者が入力したメモの読み書きから始め、メモ保存は確認して行う。具体的に支援したい場面を選び、受入シナリオを先に作る。

長期記憶、リマインダー、予定・メールなど外部ツール、常時待受、声による割込みは個別に評価する。MVPの会話開始方式はボタン/押して話す方式を基準候補にし、ウェイクワードと常時待受の採否は音響とプライバシー評価後に決める。腕・首は段階導入し、未検証の段階は無駆動で会話・目だけを試せる構成にする。

後続候補は、指可動、ToF、軽い撫での認識、豊富な動作、複数人の自然な切替、バッテリー駆動。いずれも採用や予算確保を約束していない。自律移動、人物の本人認証、屋外利用、医療・介護の安全機器用途は今回の対象外。

## 体験・データ・安全の設計方針案

- 発話中・聞き取り中・考え中・接続断・ミュートを区別して伝える。感情表現は機械の状態表現であることを隠さない。
- 反応の速さ、声の好み、視線の心地よさは実測・比較後に合格値を合意する。初期の数値案を保証と扱わない。
- 音声・画像は原則保存しない。外部送信する内容、記憶保持期間、削除方法、家族・来客への表示は実装前に決める。
- 外部送信・購入・予定変更等は対象・内容を提示して利用者確認を要求する。会話の推測だけで実行しない。
- 動作安全はLLMやネットワークから独立させる。角度・速度・電流・温度・通信期限を下位制御で制限し、物理的にモーター電源を停止できるよう設計する。

具体的な未決定事項は [判断記録](decisions-risks.md)、実装単位は [WBS](wbs.md)、合格条件は [検証計画](verification.md) を正本とする。
