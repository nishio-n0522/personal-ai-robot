## 記録の書式

実行ごとに `T番号 / 日付 / 実行者 / HW型番・版 / ソフトcommit / 設定 / 入力条件 / 合格値の合意日 / 測定値 / 合否 / 証拠相対パス / 残課題` を残す。公開用には個人情報を除いた集計を使う。未達時はゲートを止め、原因・再試験条件を記録してから再開する。
