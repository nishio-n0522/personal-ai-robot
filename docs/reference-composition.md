# 目のパラメータと観察メモ

## 現行の形

円形466px表示面と開口部を分離。初期はたれ目で、外側の目尻を内側より28px下げて左右を鏡映する。上側の制御点を下側へ補間し、閉眼時に一致させる。通常の開度は変えず、常に眠い表情には固定しない。

内傾8度・まっすぐな開口部、過去のアーモンド形などを比較できる。内傾の回転をたれ目に重ねると目尻が上がるため、たれ目は別形状にする。

## 虹彩・瞳孔・寄せ

基準虹彩半径172px、中心(244,211)。虹彩は円に近く保ち、瞳孔の幅だけ3%抑える。上側の暗部をつなげ、下側の色と白目を見せる。標準倍率85%で半径146.2px。瞳孔・反射も同率で縮小する。倍率は70〜115%、100%へ復元可能。

寄せ具合は0〜100px、初期10。画面左は正方向、右は負方向へ、虹彩・瞳孔・反射をまとめて動かす。開口部や顔は動かさない。

`36*gazeX + side*(convergence-min(convergence,24)*abs(gazeX))`

正面では表示値と同じ移動量。虹彩倍率は寄せ量に掛けない。端での減衰は最大24px、合成移動は最大±112px。まぶたによる自然な遮蔽を許容する。単調性と0への復元をテストする。

## ハイライト

丸1点、大小2点、窓反射、星、ハート、小さなきらめき、弧、なし。サイズ50〜160%、明るさ0〜100%。サイズは反射だけに適用し、パターン切替でも保持する。従来の丸の標準描画には控えめな下側の反射も含まれる。

## 見た目の評価

寄せ調整後に「寄せたら明らかによくなってきました」、さらに「めっちゃよくなりました」という評価を得た。個別の主観評価であり、一般的な怖さの解消を意味しない。好評だった一例はペンギン、たれ目、青緑、虹彩70%、寄せ80、視線(-1,1)、瞳孔.43、開き1、自動視線OFF。これは参考設定であり初期値へ強制しない。

参考の複数デザインは、円に近い虹彩、縦長の虹彩、複数反射などが異なる。すべてを同じ楕円へ変えるのではなく、見える輪郭、遮蔽、陰影を分けて検討する。元画像や切り抜きは公開対象に含めない。
